# Harness controller

A small deterministic program behind Cain on Discord that keeps the
ledger, and holds the only keys that can change anything. Models are engines: they
read what they are handed and return an answer or a typed proposal. They never hold
a credential.

This repository is also a Home Assistant add-on repository. The harness add-on lives in
`harness/`, and its Python package in `harness/app/harness`. It uses only the
standard library. A second add-on, `cain/`, runs Cain: a Claude Code session that
answers a private Discord bot (Anthropic's Discord channel plugin); it holds no harness keys.

## Invariants

Each invariant has tests. Security checks are also mutation-tested when they are
written: a check is broken on purpose in a scratch copy and a test must fail. That is
done by hand, not on every run, and the script is not in this repository, so it is
evidence about the release it was run on, not a standing guarantee. For the Family calendar add in 0.5.0, the last full pass ran 248 breaks: 236 were caught and 2 more were caught by a failing test fixture. 7 survived, got tests, and were caught on a rerun. The other 3 survivors changed nothing a test could see: 1 was redundant code, now removed, and 2 are noted as equivalent. A run that fails to import counts as not applied, never as caught. For 0.5.1, 93 new breaks were run: 88 were caught, and 5 survived, got tests, and were caught on a rerun. 18 more covered the fixes after that release's review: 14 were caught, 4 survived, got tests, and all 18 were caught on a rerun. The earlier 248 were not all run again on 0.5.1. For 0.6.0, 80 new breaks were run on keeping Family true to Gmail: all were caught after the survivors got tests. Earlier breaks were not run again.

## Run the tests

    python3 -m pytest -q

## Status

Stage S1: read-only calendars (Google, and iCloud Family pushed in by Home Assistant)
in the morning digest. From 0.5.0 the app can write to one calendar: it can add an
event to iCloud Family, and undo that add. That is off until he turns it on with a tap,
and every other effect stays locked. See `harness/CHANGELOG.md`.
